##### list comprehension

```python
numbers = [1,2,3,4,5,6]
even_numbers = [x for x in numbers if x % 2 ==0]
print(even_numbers)
labels = ["even" if x % 2 == 0 else "odd" for x in numbers]
print(labels)
```
