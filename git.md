

#### Github: 
 
W3School reference: https://www.w3schools.com/git/default.asp 

Basic commands: 
```

# Create the repositories 
# git checkout new branch 
git checkout -b <branch name>

# To switch between branch 
git checkout <branch>

# add changes in the
git add . 

# check the status of the github commit
git status 

# commit the changes into git before push code to github repositories
git commit -m "<mention message to display in the commits>"

# push the code to remote repositories like github 
git push --remote-origin <branch name>

```
